# Oba's Estates

Private real estate website for **Oba's Estates** — Lagos and Abuja.

Built with **Bootstrap 5**, custom CSS, and vanilla JavaScript. No build step required.

## Pages

- `index.html` — home, search, featured homes
- `listings.html` — filterable collection
- `listing.html?id=...` — property detail
- `about.html` — the house
- `services.html` — sales, lettings, off-market
- `contact.html` — enquiry form
- `saved.html` — saved homes (stored in the browser)

## Open locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 5500
```

Then visit http://localhost:5500
